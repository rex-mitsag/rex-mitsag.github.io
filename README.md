# Sagnik — Personal Portfolio

A lightweight, responsive personal portfolio designed to deploy directly to GitHub Pages.

## Files

- `index.html` — page structure and content
- `styles.css` — responsive styling, dark/light theme
- `script.js` — theme switcher, reveal animations, current year
- `favicon.svg` — browser icon

## Before publishing

Search `index.html` for these placeholders and replace them:

- `YOUR_GITHUB_USERNAME`
- `YOUR_LINKEDIN_USERNAME`
- `YOUR_EMAIL@example.com`

You can also update the experience/project wording to match your final CV.

## Deploy to GitHub Pages

1. Create a GitHub repository named `<your-github-username>.github.io`.
2. Upload all files from this folder to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then save.
6. GitHub will publish the site at `https://<your-github-username>.github.io`.

## Custom domain

If you buy a custom domain, add it under:

**Repository → Settings → Pages → Custom domain**

Then configure the domain's DNS records according to GitHub's current Pages documentation.

No backend or build step is required.
